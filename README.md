# SleepMate

**SleepMate** is a sleep tracking app built with SwiftUI and CoreData. It helps users log their sleep, track sleep quality, and view insights to improve their sleep habits.

## Features

- Easy-to-use interface for logging and editing sleep records
- Sleep quality ratings using emojis
- Calendar view for browsing sleep history by day
- Visual statistics:
  - Circular chart showing sleep satisfaction percentage
  - Calculation of optimal bedtime
  - Average sleep duration tracking
- Bedtime reminders with notifications

## Technologies

- SwiftUI
- CoreData
- UserNotifications
- MVVM architecture
- Custom diagrams
